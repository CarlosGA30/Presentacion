Diseño de Software

Acerca del Proyecto

Este sitio web educativo ha sido desarrollado para explicar el concepto de Estado de Objeto y el patrón de diseño State.

El objetivo es demostrar cómo una arquitectura modular y el uso de patrones de diseño pueden mejorar la mantenibilidad y escalabilidad del código.

Stack Tecnológico

  • HTML5 Semántico
  • TailwindCSS
  • JavaScript ES6 Modules
  • Bootstrap Icons
